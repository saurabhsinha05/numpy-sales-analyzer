# NumPy Sales Analyzer

A simple sales analysis project built using Python and NumPy.

## Features

- Calculate daily sales
- Calculate product-wise sales
- Calculate average daily sales
- Find the highest sales day
- Find the highest-selling product
- Find days with sales above ₹7000
- Calculate total sales
- Calculate product-wise percentage contribution
- Classify daily sales as Excellent, Good, Average, or Low

## Technologies Used

- Python
- NumPy
